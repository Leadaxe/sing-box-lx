# Support sing-box-lx

> RU: [donate.ru.md](donate.ru.md)

sing-box-lx is free and has no paid features. Development happens in spare time:
upstream merges within days of every release, compatibility with current Xray and
AmneziaWG servers, and the bugs that show up in real use of the desktop launcher,
LxBox and routers. The project has no other income.

Donating is entirely optional — the core works the same for everyone.

## Other ways to help

Just as valuable:

- **A star on GitHub** — [sing-box-lx](https://github.com/Leadaxe/sing-box-lx).
  Stars are how new users find the project.
- **A bug report** — [GitHub issues](https://github.com/Leadaxe/sing-box-lx/issues).
  A config and a log of the failure save weeks of guesswork.
- **A review** — the [Telegram group](https://t.me/singbox_launcher/4317).
- **Using the apps built on the core** — [LxBox](https://github.com/Leadaxe/LxBox)
  for Android and the [desktop launcher](https://github.com/Leadaxe/singbox-launcher).

Into keeping the project moving: time spent on the core and the apps, test
devices and routers, and the infrastructure that builds and checks every release.
