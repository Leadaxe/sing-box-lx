# Поддержать sing-box-lx

> EN: [donate.md](donate.md)

sing-box-lx бесплатный, платных функций нет. Разработка идёт в свободное время:
мерж апстрима в течение нескольких дней после каждого релиза, совместимость с
актуальными серверами Xray и AmneziaWG, баги, которые всплывают в живой работе
десктопного лаунчера, LxBox и роутеров. Других источников дохода у проекта нет.

Поддержка — дело добровольное, ядро работает одинаково для всех.

## Как ещё помочь, если не деньгами

Это не менее ценно:

- **Звезда на GitHub** — [sing-box-lx](https://github.com/Leadaxe/sing-box-lx).
  По звёздам проект находят новые пользователи.
- **Баг-репорт** — [issues на GitHub](https://github.com/Leadaxe/sing-box-lx/issues).
  Конфиг и лог сбоя экономят недели догадок.
- **Отзыв** — [Telegram-группа](https://t.me/singbox_launcher/4317).
- **Пользоваться приложениями на этом ядре** — [LxBox](https://github.com/Leadaxe/LxBox)
  для Android и [десктопный лаунчер](https://github.com/Leadaxe/singbox-launcher).
