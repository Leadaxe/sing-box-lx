## 🆕 What's new

### 🕸️ Tailscale in the desktop and router binaries

Every release archive is now built with `with_tailscale`:

- `tailscale` endpoint, `tailscale` DNS transport, `tailscale` certificate provider and the `derp` service — upstream sing-box features, upstream configuration.
- Targets: darwin / windows × amd64/arm64, the Windows 7 32-bit build, `linux-amd64/arm64/armv7/mipsle-softfloat` (static musl) and `linux-mips-softfloat`.
- Pure Go, so it builds on every target that already exists; nothing to install next to the binary.
- Size: darwin/arm64 49.8 → 63.2 MB, mips softfloat 56.2 → 72.2 MB. Check free flash on small routers before upgrading.
- Not in the Android AAR: LxBox has no Tailscale UI and it is the largest dependency in the APK. (SPEC 004)

## 🔧 Changed

### ⏱️ MASQUE: tunnel idle-suspend is off by default

Without `idle_timeout` the MASQUE tunnel used to suspend after 5 minutes of silence on every platform; the first request after each pause paid a full QUIC handshake, a CONNECT-IP setup and a new gVisor stack, in exchange for ~6 MB RSS and one keepalive packet every 30 s.

- Now only a positive `idle_timeout` (for example `"5m"`) enables suspend.
- A missing key, `"0s"` and negative values are equivalent: the tunnel stays up until the outbound is closed, kept alive by `keep_alive_period` (30 s).
- Battery-bound hosts that want the old behaviour set `"idle_timeout": "5m"` explicitly. (SPEC 021)

### ⏱️ MASQUE: idle-suspend туннеля по умолчанию выключен
