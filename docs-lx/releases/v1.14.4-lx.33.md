## 🔧 Changed

### 🎭 `lx.quic_sniff_decoy` is an object; the byte goes on the retry by default

- Before (lx.30–lx.32): `"off"` / `"direct"` / `"detour"` / `"all"` or `true`; the byte went before the QUIC Initial on every dial of every QUIC node on the selected paths.
- Now: `{"mode", "outbound_type", "detour_type", "send"}`. The old forms fail with `lx.quic_sniff_decoy must be an object: {mode, outbound_type, detour_type, send}`.
  - `mode` — `off` (default) / `direct` / `detour` / `all`: on which paths the byte is allowed, as before.
  - `outbound_type` — default `["masque"]`; allowed `masque`, `hysteria2`, `tuic`, `trusttunnel`, `vless`, `vmess`, `trojan`, `wireguard`. The byte goes only where the node opens QUIC: masque h3, trusttunnel with `quic: true`, vless/vmess/trojan with xhttp over h3, wireguard before a QUIC-like AmneziaWG burst.
  - `detour_type` — default `["vless"]`; any outbound type except groups. The type of the nearest relay is read at dial time from the member a group has actually selected.
  - `send` — `retry` (default): the first attempt goes without the byte, a failed one is repeated with it — at once on a fast non-timeout error, otherwise on the next dial; a failure with the byte resets the node back to without. `always` — the lx.30–lx.32 behaviour. `send` does not apply to `wireguard`: the byte goes on every handshake.
- Migration: `"detour"` → `{"mode": "detour"}`, `true` → `{"mode": "all"}`; add `"send": "always"` to keep the byte on every dial.
- Not caught by the retry: a handshake that silently lands elsewhere (tuic with `insecure`), a silent relay (the first URL test fails, the second passes), TLS sniffing on h2.
- Unit-tested; no live run on the object form yet. (SPEC 151)

### 🧹 `lx.awg_masquerade` removed

- Before (lx.31–lx.32): `"all"` (default in lx.32) / `"direct"` decided whether the AmneziaWG masquerade burst went through a `detour`.
- Now: the burst is sent on every path; any value of the key fails with `lx.awg_masquerade is removed: the AmneziaWG masquerade burst is sent on every path`.
- An AWG endpoint with `ip=quic` through a `detour` to a relay with Xray QUIC sniffing: `lx.quic_sniff_decoy` with `wireguard` in `outbound_type`. (SPEC 153)

## 🔧 Изменено

### 🎭 `lx.quic_sniff_decoy` — объект; байт по умолчанию на повторе

- Было (lx.30–lx.32): `"off"` / `"direct"` / `"detour"` / `"all"` или `true`; байт шёл перед QUIC Initial на каждом дозвоне любого QUIC-узла на выбранных путях.
- Стало: `{"mode", "outbound_type", "detour_type", "send"}`. Старые формы — ошибка `lx.quic_sniff_decoy must be an object: {mode, outbound_type, detour_type, send}`.
  - `mode` — `off` (дефолт) / `direct` / `detour` / `all`: на каких путях байт разрешён, как раньше.
  - `outbound_type` — дефолт `["masque"]`; допустимы `masque`, `hysteria2`, `tuic`, `trusttunnel`, `vless`, `vmess`, `trojan`, `wireguard`. Байт идёт только там, где узел открывает QUIC: masque h3, trusttunnel с `quic: true`, vless/vmess/trojan с xhttp по h3, wireguard перед QUIC-образной пачкой AmneziaWG.
  - `detour_type` — дефолт `["vless"]`; любой тип outbound, кроме групп. Тип ближайшего релея читается при дозвоне по участнику, которого группа фактически выбрала.
  - `send` — `retry` (дефолт): первая попытка без байта, неудачная повторяется с байтом — сразу при быстрой ошибке не-таймауте, иначе на следующем дозвоне; неудача с байтом возвращает узел к попыткам без него. `always` — поведение lx.30–lx.32. На `wireguard` `send` не действует: байт на каждом рукопожатии.
- Миграция: `"detour"` → `{"mode": "detour"}`, `true` → `{"mode": "all"}`; `"send": "always"` — байт на каждом дозвоне, как раньше.
- Что ретрай не ловит: хендшейк, ушедший не туда без ошибки (tuic с `insecure`), молчащий релей (первый URL-тест падает, второй проходит), сниффинг TLS на h2.
- Покрыто юнит-тестами; живого прогона на объектной форме не было. (SPEC 151)

### 🧹 Удалён `lx.awg_masquerade`

- Было (lx.31–lx.32): `"all"` (дефолт в lx.32) / `"direct"` решали, идёт ли маскировочная пачка AmneziaWG через `detour`.
- Стало: пачка шлётся на любом пути; любое значение ключа — ошибка `lx.awg_masquerade is removed: the AmneziaWG masquerade burst is sent on every path`.
- AWG-endpoint с `ip=quic` через `detour` на релей с QUIC-сниффингом Xray: `lx.quic_sniff_decoy` с `wireguard` в `outbound_type`. (SPEC 153)
