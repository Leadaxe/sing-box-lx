## 🔄 Changed

### 📦 Fully back in step with upstream

Two hundred and seventeen upstream commits landed here. Among them: a fix for a
TUN dispatcher deadlock, more consistent URLTest results, a reworked Tailscale
status watcher that reconnects instead of going quiet, and refreshed network
libraries — gvisor, QUIC, Tailscale.

Dependencies were brought in step first, before the merge itself. That order
matters: doing it the other way round is what produced a broken build two
releases ago. The WireGuard component was missing exactly one upstream change
(a batching improvement for macOS sends) and it was taken cleanly; the rest
already matched.

Where upstream had since fixed something this fork had solved on its own, the
upstream version was preferred and ours retired — but only after checking that
theirs covered the whole case. The Tailscale status watcher is one such place:
upstream's version delivers updates without blocking and recovers from a
dropped notification bus, which ours did not do.

Everything this fork adds is intact: the detour chain, the DNS query stream,
URLTest pooling, idle-suspend for sleeping endpoints, the AmneziaWG obfuscation,
and all eight of the extended client commands.

## 🐛 Fixed

### 💥 A crash while shutting down a WireGuard endpoint

Merging code is not only about resolving the places where two sides disagree —
the quieter danger is the places where they *appear* to agree and get stitched
together automatically. Two such spots slipped in here, and neither would have
been visible by reading the merge.

The first left a leftover line of upstream code sitting underneath our own
safety check, in the path that releases a sleeping endpoint. Reaching it meant
dereferencing something already released — a crash. Only the regression test
for that feature caught it.

The second dropped an import that our idle-suspend interface depends on, which
the build caught immediately.

Both are fixed. The regression test that found the first one is the same one
written when that feature shipped, which is the argument for keeping such tests
around.

## 🔄 Изменено

### 📦 Полностью в ногу с upstream

Перенесены двести семнадцать изменений upstream. Среди них: исправление
взаимоблокировки в диспетчере TUN, более стабильные результаты URLTest,
переработанный наблюдатель состояния Tailscale, который переподключается вместо
того, чтобы замолчать, и обновлённые сетевые библиотеки — gvisor, QUIC,
Tailscale.

Зависимости приводились в порядок первыми, до самого слияния. Порядок здесь
важен: именно обратный порядок привёл к сломанной сборке два выпуска назад.
WireGuard-компоненту не хватало ровно одного изменения upstream (улучшение
пакетной отправки для macOS), оно перенесено начисто; остальное уже совпадало.

Там, где upstream к этому времени исправил то же, что форк решал сам,
предпочтён вариант upstream, а наш снят — но только после проверки, что их
вариант покрывает случай целиком. Наблюдатель состояния Tailscale — как раз
такое место: версия upstream доставляет обновления не блокируя и
восстанавливается после обрыва шины уведомлений, чего наша не умела.

Всё, что добавляет форк, на месте: цепочка detour, поток DNS-запросов,
пул URLTest, засыпание простаивающих подключений, обфускация AmneziaWG и все
восемь расширенных клиентских команд.

## 🐛 Исправлено

### 💥 Падение при освобождении WireGuard-подключения

Слияние кода — это не только разбор мест, где две стороны спорят. Тише и
опаснее места, где они лишь *кажутся* согласными и склеиваются автоматически.
Два таких попали сюда, и ни одно не было бы заметно при чтении слияния.

Первое оставило строку кода upstream под нашей собственной проверкой — в пути,
который освобождает спящее подключение. Дойти до неё означало обратиться к уже
освобождённому объекту, то есть упасть. Поймал это только регрессионный тест
той самой возможности.

Второе потеряло импорт, от которого зависит наш интерфейс засыпания
подключений, — это сразу поймала сборка.

Оба исправлены. Тест, нашедший первое, был написан тогда же, когда выпускалась
сама возможность, — и это лучший довод в пользу того, чтобы такие тесты жили.
