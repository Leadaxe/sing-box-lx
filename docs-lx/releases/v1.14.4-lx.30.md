QUIC nodes (MASQUE h3, Hysteria2, TUIC) can now pass through a third-party relay that sniffs SNI, and no longer die through a stream detour when the server sends a datagram larger than the read buffer. A Tailscale endpoint takes a new auth key and switches on/off without a restart; Taildrop can be turned off per node. The `route.lx_idle_*` aliases are removed: configs must use `lx.wg.*`.

QUIC-узлы (MASQUE h3, Hysteria2, TUIC) теперь проходят через чужой релей, который сниффит SNI, и больше не умирают через потоковый detour, когда сервер шлёт датаграмму больше буфера чтения. Tailscale-endpoint принимает новый ключ и включается/выключается без перезапуска; Taildrop выключается на узле. Алиасы `route.lx_idle_*` удалены: в конфиге нужно `lx.wg.*`.

## 🆕 What's new

### 🎭 QUIC through relays that sniff SNI: `lx.quic_sniff_decoy`

- Before: a relay running Xray `sniffing` (`destOverride` with `quic`, no `routeOnly`) read the SNI from the QUIC Initial and sent the flow to that name. MASQUE h3 to WARP failed with `different public key than pinned`; Hysteria2/TUIC with a fronting SNI landed on a foreign host. h2 through the same relays worked.
- Now: with the root key `lx.quic_sniff_decoy` each MASQUE h3, Hysteria2 and TUIC dial sends one byte `0x00` ahead of the first Initial. The relay decides on the first datagram, its QUIC sniffer drops out, the destination stays as dialled. The server discards the byte (QUIC fixed bit clear). No delay, no extra handshake.
- Modes: `"off"` (default), `"direct"` — dials on the device's own socket only, `"detour"` — dials carried by another outbound only, `"all"`. `true`/`false` mean `"all"`/`"off"`.
- Measured against Xray `v26.10.31`: MASQUE h3 → WARP 0/5 → 5/5, 2 min alive 12/12; Hysteria2 and TUIC 0/4 → 4/4; three live public sniffing relays 0/3 → 3/3 (one with an unrelated tunnel reset 2/3). Hysteria2 port hopping (`server_ports`) not covered. (SPEC 151)

### 🔑 Tailscale: new auth key and on/off without a restart

- Before: a node rejected by control (`invalid key: API key does not exist`) took a new key only through a config edit and a full service restart.
- Now: RPC `TailscaleLogin(endpointTag, authKey)` logs the running endpoint in; an empty key starts interactive login, the AuthURL shows up in the endpoint status. `SetEndpointEnabled` switches a Tailscale endpoint off and on keeping identity and state; dials through a disabled endpoint fail at once instead of timing out. `endpointState`: `up`/`disabled`/`down`.
- Checked in LxBox on Android against `login.tailscale.com`: Running in ~2 s after Logout and after a rejected key. (SPEC 149)

### 📥 Taildrop off per node, sender of received files

- Endpoint key `disable_taildrop: true`: incoming files are refused with 403 `Taildrop is disabled on this node`, sending returns `FailedPrecondition`. Changes on reload.
- `TaildropFile.senderID`: stable node ID of the sender next to `senderName`; empty for files left on disk from before a core restart. (SPEC 149)

## 🔧 Changed

### ⚠️ `route.lx_idle_suspend`, `route.lx_idle_suspend_reachable`, `route.lx_idle_teardown` removed

- A config with these keys no longer starts (`unknown field`). Use `lx.wg.idle_suspend`, `lx.wg.idle_suspend_reachable`, `lx.wg.idle_teardown`. (SPEC 098)

### 🔒 Dependencies by govulncheck

- `golang.org/x/net` v0.62.0, `golang.org/x/crypto` v0.58.0, `google.golang.org/grpc` v1.83.2; reachable vulnerabilities 10 → 0.

## 🐛 Fixed

### 📦 QUIC through a stream detour no longer dies on an oversize datagram

- Before: MASQUE h3 (and Hysteria2/TUIC) with `detour` through a VLESS/XUDP relay over ws, gRPC or XHTTP died 1–5 s after the handshake with `quic: transport closed: short buffer`: Cloudflare's PMTUD probes of 1453–1462 bytes exceed the 1452-byte read buffer.
- Now: such a conn truncates an oversize datagram like a kernel socket does, and QUIC drops it. The direct path is unchanged. (SPEC 150)

## 🧰 Tools

- oom-killer logs its mode and thresholds at start: `mode: runtime_limit, limit: 200 MB, trigger: 195 MB, armed: 190 MB`. (SPEC 148)
- `lxd` builds for FreeBSD again.

## 🆕 Что нового

### 🎭 QUIC через релеи, которые сниффят SNI: `lx.quic_sniff_decoy`

- Было: релей с Xray `sniffing` (`destOverride` с `quic`, без `routeOnly`) читал SNI из QUIC Initial и уводил поток на это имя. MASQUE h3 к WARP падал с `different public key than pinned`, Hysteria2/TUIC с подставным SNI попадали на чужой хост. h2 через те же релеи работал.
- Стало: с корневым ключом `lx.quic_sniff_decoy` каждый дозвон MASQUE h3, Hysteria2 и TUIC шлёт один байт `0x00` перед первым Initial. Релей решает по первой датаграмме, его QUIC-сниффер выбывает, назначение остаётся набранным. Сервер отбрасывает байт (снят fixed bit QUIC). Без задержки и лишнего хендшейка.
- Режимы: `"off"` (по умолчанию), `"direct"` — только дозвоны на собственном сокете устройства, `"detour"` — только дозвоны через другой outbound, `"all"`. `true`/`false` = `"all"`/`"off"`.
- Замеры против Xray `v26.10.31`: MASQUE h3 → WARP 0/5 → 5/5, 2 минуты жизни 12/12; Hysteria2 и TUIC 0/4 → 4/4; три живых публичных сниффящих релея 0/3 → 3/3 (на одном посторонний сброс туннеля, 2/3). Port hopping Hysteria2 (`server_ports`) не покрыт. (SPEC 151)

### 🔑 Tailscale: новый ключ и вкл/выкл без перезапуска

- Было: узел, которому control отказал (`invalid key: API key does not exist`), брал новый ключ только правкой конфига и полным рестартом сервиса.
- Стало: RPC `TailscaleLogin(endpointTag, authKey)` логинит работающий endpoint; пустой ключ — интерактивный вход, AuthURL появляется в статусе endpoint'а. `SetEndpointEnabled` выключает и включает Tailscale-endpoint с сохранением идентичности и состояния; дозвоны через выключенный endpoint отказывают сразу, а не по таймауту. `endpointState`: `up`/`disabled`/`down`.
- Проверено в LxBox на Android против `login.tailscale.com`: Running за ~2 с после Logout и после отвергнутого ключа. (SPEC 149)

### 📥 Taildrop выключается на узле, отправитель полученного файла

- Ключ endpoint'а `disable_taildrop: true`: входящие файлы отклоняются с 403 `Taildrop is disabled on this node`, отправка — `FailedPrecondition`. Меняется reload'ом.
- `TaildropFile.senderID`: stable node ID отправителя рядом с `senderName`; пустой у файлов, оставшихся на диске с прошлого запуска ядра. (SPEC 149)

## 🔧 Изменено

### ⚠️ Удалены `route.lx_idle_suspend`, `route.lx_idle_suspend_reachable`, `route.lx_idle_teardown`

- Конфиг с этими ключами больше не стартует (`unknown field`). Писать `lx.wg.idle_suspend`, `lx.wg.idle_suspend_reachable`, `lx.wg.idle_teardown`. (SPEC 098)

### 🔒 Зависимости по govulncheck

- `golang.org/x/net` v0.62.0, `golang.org/x/crypto` v0.58.0, `google.golang.org/grpc` v1.83.2; достижимых уязвимостей 10 → 0.

## 🐛 Исправлено

### 📦 QUIC через потоковый detour больше не умирает на большой датаграмме

- Было: MASQUE h3 (и Hysteria2/TUIC) с `detour` через VLESS/XUDP-релей поверх ws, gRPC или XHTTP умирал через 1–5 с после хендшейка с `quic: transport closed: short buffer`: PMTUD-пробы Cloudflare по 1453–1462 байт больше буфера чтения 1452.
- Стало: такой conn обрезает большую датаграмму, как сокет ядра, и QUIC её отбрасывает. Прямой путь не меняется. (SPEC 150)

## 🧰 Инструменты

- oom-killer пишет режим и пороги при старте: `mode: runtime_limit, limit: 200 MB, trigger: 195 MB, armed: 190 MB`. (SPEC 148)
- `lxd` снова собирается под FreeBSD.
