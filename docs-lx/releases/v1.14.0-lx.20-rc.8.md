## 🔧 Internal

### 🧩 Two long-standing merge hazards removed

Twice in a row — in the merge of 235 upstream commits, and again in the 217-commit
merge shipped as `rc.7` — the same two files broke in the same way, and neither
break was visible while reviewing the merge. Both were caught by the build and
by tests, and fixed before those releases went out; but the underlying shape was
still there, waiting for the next merge.

It is worth being precise about the cause, because the obvious explanation is
wrong: upstream was not removing anything. That code simply does not exist on
their side. What broke was the *shape* of our own additions — each sat in a spot
where both sides append, so the merge tool combined them into something neither
side had written, without reporting a conflict.

Both are now restructured rather than re-patched:

- The idle-suspend interfaces moved into a file of their own, taking the import
  that only they needed. The file they came from is now byte-for-byte identical
  to upstream's, so there is nothing left there to merge wrongly.
- The safety check when releasing a sleeping endpoint became a single call
  instead of a block sitting next to upstream's own closing line. Our difference
  in that function is now one line, which a future upstream change will collide
  with loudly instead of silently absorbing.

The rest of the tree was checked for additions of the same shape; there are
none. Behaviour is unchanged, and the regression tests that caught the original
crash all pass.

## 🔧 Внутреннее

### 🧩 Убраны две давние ловушки слияния

Дважды подряд — при слиянии 235 изменений upstream и снова при слиянии 217,
вышедшем как `rc.7` — ломались одни и те же два файла одинаковым образом, и ни
одна поломка не была видна при разборе слияния. Обе поймали сборка и тесты,
обе исправлены до выпуска; но сама форма оставалась на месте и ждала следующего
слияния.

О причине стоит сказать точно, потому что очевидное объяснение неверно: upstream
ничего не вычищал. Этого кода у него просто нет. Ломалась *форма* наших
собственных добавок — каждая стояла там, где дописывают обе стороны, поэтому
инструмент слияния соединял их в нечто, чего не писала ни одна сторона, и о
конфликте при этом не сообщал.

Оба места теперь переустроены, а не залатаны заново:

- Интерфейсы засыпания подключений переехали в отдельный файл вместе с
  импортом, который нужен был только им. Файл, откуда они ушли, теперь
  побайтово совпадает с апстримовым — там просто нечего слить неправильно.
- Проверка при освобождении спящего подключения превратилась в один вызов
  вместо блока, стоявшего рядом с завершающей строкой upstream. Наше отличие в
  этой функции теперь — одна строка, и будущая правка upstream столкнётся с ней
  явно, а не поглотит незаметно.

Остальное дерево проверено на добавки такой же формы — их нет. Поведение не
меняется, регрессионные тесты, поймавшие исходное падение, проходят.
