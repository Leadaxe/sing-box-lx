## 🔧 Changed

### ⬆️ Upstream base: sing-box v1.14.2

- hijack-dns reports handshake success before handling the query (connection trackers see the DNS connection as established).
- Fork submodule `sing-tun` merged with upstream's pin `ddaa4ca25e3b`; the fork's own change (acceptLoop self-heal) is intact. `sing-quic` bumped with upstream. ([SPEC 102](https://github.com/Leadaxe/sing-box-lx/blob/lx/SPECS/TASKS/102-UPSTREAM_SYNC_1_14_2/SPEC.md))
