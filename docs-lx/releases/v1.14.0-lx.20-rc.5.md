## 🔧 Changed

### 🔄 Two months of upstream fixes are now in

The fork tracks SagerNet's sing-box, and that base had moved 235 commits ahead.
This release closes that gap entirely. Most of it is invisible plumbing, but a
few things matter in daily use: a deadlock in the TUN packet dispatcher, a race
in DNS rule matching where one rule could block another, DNS suffix matching and
TCP DNS retries, and several WireGuard corrections around peer lookup and packet
batching.

Everything the fork adds on top — AmneziaWG, XHTTP, the post-quantum VLESS
layer, node balancing, the idle power saving, DNS groups — is unchanged and was
verified piece by piece after the merge. Upstream features outside a VPN
client's job (OpenVPN, OpenConnect, USB/IP, bridges, desktop-only builds) are
deliberately not compiled in, as before.

Nothing in this release changes how the app behaves for you. It exists so the
next feature lands on a current base instead of a two-month-old one. (SPEC 051)
