## 🔧 Changed

### 🔄 Upstream fixes up to 2026-11-14 are in

- REALITY client: the node's configured time and root pool are used, and the cover request after a failed verification is sent before the error returns.
- ShadowTLS v2: client authentication works with an X25519MLKEM768 key share.
- SSH outbound: the handshake has a timeout.
- QUIC: correct buffer sizes on the sockets hidden from quic-go.
- Sniffing: a sniffed ECH public name no longer replaces the domain known from DNS; sniffers no longer clear the reverse-mapped domain.
- auto-redirect on Linux: older kernels, marks of other programs, missing `nft_fib` / `nft_queue` modules, large rule sets.
- The `random` uTLS fingerprint no longer picks Edge 85 or iOS 14.

### 🧬 uTLS moved to v1.9.0-alpha.1

- Firefox 148 and Safari 26.3 fingerprints now come from the uTLS project itself; the fork keeps only the Chrome 155 preset (`chrome_155`, opt-in) and a memory release after the handshake.
- `chrome` stays Chrome 133. The REALITY client version sent to the server stays `26.3.27`, as Xray v26.7.11 and newer require. (SPEC 053, SPEC 086)

## 🐛 Fixed

### 🎭 AmneziaWG QUIC masquerade kept its transport parameters across the uTLS update

- The new uTLS overwrites the transport parameters of a preset ClientHello; without the fix the masquerade packet would have gone out with an empty list. lx.34 is not affected.

## 🧰 Tools

### 📦 No upstream drift

- The build carries sing-box v1.14.4 plus all 71 later `upstream/stable` commits (2026-11-14).

## 🔧 Изменено

### 🔄 Исправления апстрима по 2026-11-14 включены

- REALITY-клиент: используются время и корневой пул из настроек узла, а запрос-прикрытие после несошедшейся проверки уходит до возврата ошибки.

- SSH-outbound: у рукопожатия появился таймаут.
- QUIC: верные размеры буферов у сокетов, скрытых от quic-go.
- Сниффинг: прочитанное имя ECH больше не подменяет домен, известный из DNS; снифферы не стирают домен обратного отображения.
- auto-redirect на Linux: старые ядра, метки других программ, отсутствие модулей `nft_fib` / `nft_queue`, большие наборы правил.
- Отпечаток uTLS `random` больше не выбирает Edge 85 и iOS 14.

### 🧬 uTLS переведён на v1.9.0-alpha.1

- Отпечатки Firefox 148 и Safari 26.3 теперь приходят из самого проекта uTLS; в форке остались только пресет Chrome 155 (`chrome_155`, включается явно) и освобождение памяти после рукопожатия.
- `chrome` остаётся Chrome 133. Версия REALITY-клиента, объявляемая серверу, остаётся `26.3.27` — этого требуют Xray v26.7.11 и новее. (SPEC 053, SPEC 086)

## 🐛 Исправлено

### 🎭 QUIC-маскировка AmneziaWG сохранила transport parameters после обновления uTLS

- Новый uTLS перезаписывает transport parameters у ClientHello из пресета; без исправления маскировочный пакет ушёл бы с пустым списком. lx.34 не затронут.

## 🧰 Инструменты

### 📦 Дрейфа от апстрима нет

- В сборке sing-box v1.14.4 и все 71 более поздний коммит `upstream/stable` (2026-11-14).
