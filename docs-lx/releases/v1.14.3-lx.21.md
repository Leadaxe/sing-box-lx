## 🆕 What's new

### 🖥️ Router builds for 32-bit x86 and RISC-V

- `sing-box-<ver>-linux-386.tar.gz` — OpenWrt `i386_pentium4`, needs SSE2 (Pentium 4 and later); no build for older x86.
- `sing-box-<ver>-linux-riscv64.tar.gz` — OpenWrt `riscv64_generic`.
- Both are static musl builds with NaïveProxy and the same tag set as the other router builds; `sing-box version` reports `Platform: linux-386` / `linux-riscv64`, so `lxd update` finds them. (FEATURE 001)

### 🗜️ UPX-packed copies for small-flash routers

- `sing-box-<ver>-linux-arm64.upx.tar.gz` and `sing-box-<ver>-linux-mipsle-softfloat.upx.tar.gz`, beside the plain archives, in every release including rc. Target: routers with 128 MB NAND and no USB (MT7981 aarch64, MT7621 mipsel), where the 75–90 MB binary does not fit the overlay.
- Size: ~17 MB on flash instead of 75–90 MB; the download itself is only ~1.6× smaller.
- Cost: the binary unpacks itself into RAM at every start — about +17 MB RSS (measured on x86) and a 15–20 s cold start on mipsle. Some older router kernels refuse the packed binary: if it does not start, use the plain archive.
- UPX 5.2.1, pinned by sha256; every packed binary must run `version` under qemu before it is published. (FEATURE 001)

## 🔧 Changed

### 🔄 `lxd update` keeps a packed binary packed

- A UPX-packed binary (`UPX!` in its first 4 KiB) updates to the `.upx.tar.gz` copy of the new release. A release without that copy falls back to the plain archive and says `no UPX-packed copy in this release, falling back to the plain binary`.
- The free-space check now also runs against the new binary's size from its tar header (+10 %) before anything is written. Before: only the running binary's size was checked, so a 17 MB packed binary passed, the archive was downloaded and the write failed on a full overlay. Now the update stops after the first kilobytes of the archive with `need N KiB free beside <path>, have M`; the running binary is never touched.
- Not affected: plain binaries, the version comparison, the swap, the restart and the health steps. (SPEC 129)

## 🧰 Tools

### 📦 OpenWrt installer 1.3

- Architectures: `i686` → `linux-386`, `riscv64` → `linux-riscv64`, besides aarch64, x86_64, armv7l, mips and mipsel.
- Free-space warning at 100 MB (was 50 MB, written for a ~41 MB binary); the space of an already installed binary counts as free.
- With less than 100 MB free and a `.upx` copy in the release for this architecture, the installer asks to install the packed binary (default: yes).

## 🔧 Изменено

### 🔄 `lxd update` оставляет сжатый бинарь сжатым

- Бинарь, сжатый UPX (`UPX!` в первых 4 КиБ), обновляется на `.upx.tar.gz`-копию нового релиза. Нет такой копии в релизе — ставится обычный архив со строкой `no UPX-packed copy in this release, falling back to the plain binary`.
- Свободное место проверяется ещё и по размеру нового бинаря из его tar-заголовка (+10 %), до записи первого байта. Было: сверялся только размер работающего бинаря — сжатые 17 МБ проходили, архив скачивался, и запись падала на заполненном overlay. Стало: обновление останавливается на первых килобайтах архива с `need N KiB free beside <path>, have M`; работающий бинарь не трогается.
- Не затронуто: обычные бинари, сравнение версий, подмена, рестарт и шаги здоровья. (SPEC 129)
