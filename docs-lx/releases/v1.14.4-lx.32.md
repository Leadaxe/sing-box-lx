## 🔧 Changed

### 🎭 `lx.awg_masquerade` defaults to `"all"`

- Before (lx.31): absent key = `"direct"` — the masquerade burst (`ip`/`id`/`ib` decoy, `i1`…`i5`, `jc` junk) was sent only on the device's own socket; through a `detour` a single handshake initiation went out.
- Now: absent key = `"all"` — the burst on every path, the behaviour before lx.31. `"direct"` (or `false`) keeps the burst off a `detour`.
- An AWG endpoint with `ip=quic` through a `detour` to a relay with Xray `sniffing` (`destOverride` with `quic`, no `routeOnly`) needs one of: `lx.awg_masquerade: "direct"`, or `lx.quic_sniff_decoy: "detour"` / `"all"`. (SPEC 153)

## 🐛 Fixed

### 🔀 `detour` to a selector set to `direct` counted as a proxy path

- Before: with an AWG endpoint whose peer address is a domain (or with several peers) and a `detour` to a selector or urltest group set to `direct`, `lx.awg_masquerade: "direct"` dropped the masquerade burst and `lx.quic_sniff_decoy` picked the `detour` mode, as if the group pointed at a proxy. A single peer with an IP address was classified correctly.
- Now: no `detour`, `detour` to a `direct` outbound, and `detour` to a group of any nesting currently set to `direct` are all the direct path. The same group switched to a proxy is a detour from the next dial on.
- Applies to `lx.quic_sniff_decoy` for MASQUE, Hysteria2 and TUIC as well. Unit-tested; no live run yet. (SPEC 153)

## 🔧 Изменено

## 🐛 Исправлено

### 🔀 `detour` на селектор с выбранным `direct` считался путём через прокси

- Было: у AWG-endpoint'а с доменным адресом peer'а (или с несколькими peer'ами) и `detour` на группу selector или urltest с выбранным `direct` режим `lx.awg_masquerade: "direct"` снимал маскировочную пачку, а `lx.quic_sniff_decoy` выбирал режим `detour` — как будто группа указывала на прокси.
