# SPEC: 054 — URLTEST_PENALTY_FAILOVER

**Фича:** [URLTEST_BALANCE](../../FEATURES/007-URLTEST_BALANCE/FEATURE.md)

| Поле | Значение |
|------|----------|
| Тип | F (feature) — реакция least_test-группы на отказы боевых дайлов; дизайн владельца |
| Статус | C (complete) — фикс в дереве, юнит-тесты зелёные; полевая проверка ждёт релиза |
| Ветка | `lx` |
| Base | `008ad3ac2` (v1.14.0-lx.21 + reality minClientVer) |
| Связанные | [SPEC 052](../052-NETSTACK_CONNECT_DEADLINE/SPEC.md) (поставщик ошибок: 15s-дедлайн вместо 127s тишины), [RESEARCH 052](../052-NETSTACK_CONNECT_DEADLINE/RESEARCH.md) (ловушки S2/S6, прилипание urltest), SPEC 019 (passive_check), SPEC 020 (reachability/wake) |

**Touches:** только least_test. round_robin-пул (SPEC 019 v2) не затронут — его
инвариант «ошибка дайла не трогает пул» в силе. Апстрим-семантика удаления
history при ошибке дайла сохранена.

## Why

До этого группа не реагировала на ошибки боевых дайлов вообще (осознанный
апстрим-дизайн: причина ошибки неоднозначна — мёртвый узел / мёртвый сайт /
локальная сеть). Выбор оставался прибит к мёртвому узлу до хвоста следующего
пробного прогона — до `interval` (3 мин по умолчанию), а с passive_check и
дольше. SPEC 052 дал быстрый сигнал (ошибка за 15с вместо 127с тишины), но его
никто не потреблял: пользователь ловил 15-секундные ошибки до самого ретеста.

## Design (владельца, 2026-08-07)

Вся логика — [protocol/group/urltest_penalty_lx.go](../../../protocol/group/urltest_penalty_lx.go);
в [urltest.go](../../../protocol/group/urltest.go) — маркированные швы
(`lx: SPEC 054`): поля структуры, penalty-aware выбор в `DialContext`/`ListenPacket`,
сбросы, отключение passive-skip, `selectPenaltyAware` в `performUpdateCheck`.

**Штрафы.** Отказ боевого TCP-дайла класса «путь мёртв» даёт узлу +1:
`context.DeadlineExceeded` (в т.ч. 15s-дедлайн SPEC 052), `os.ErrDeadlineExceeded`,
`EHOSTUNREACH`/`ENETUNREACH`/`ETIMEDOUT`, `net.Error.Timeout()`. НЕ штрафуются:
RST/refused (узел донёс — назначение отказало; через другой узел тот же отказ),
`context.Canceled` (клиент ушёл сам). Сброс — **только доказательством жизни**:
успешный боевой дайл или ответ на пробу в ретесте. Никаких сбросов по времени.

**Fallback (кап 2).** После штрафа — ровно один запасной дайл через лучшего
кандидата (ранжирование ниже, минус отказавший). Успех: штраф запасного в 0,
выбор группы переезжает на него — **без `Interrupt`** (живые соединения целы),
с инвалидацией reachability-дерева (SPEC 020). Провал: симметричные штраф/
history-delete запасному, исходная ошибка — приложению; его ретрай продолжит
с уже сдвинутым выбором. Худший случай на мёртвом узле: 15с + 15с = до 30с на
первый дайл, дальше быстро.

**Аварийный режим.** Когда лучший-по-скорости (чистый min-delay, без
tolerance) набрал ≥3 штрафов, выбор — двухуровневый: **штрафы ↑, затем
задержка ↑** среди узлов с history. Победители по штрафам (обычно кучка с
нулём) соревнуются по скорости — тот же least_test, просто без штрафников.
Действует и на боевой выбор (обходя кеш `selectedOutbound*`), и на переизбор в
`performUpdateCheck`. Выход — естественный: лучший ответил (проба/дайл) →
штрафы в 0 → критерий снова скорость.

**Аварийный клапан.** Тотальные штрафы (все кандидаты с history ≥3 — умер путь
целиком, ранжировать нечего) → немедленный force-прогон проб.
Уровень-триггер: пока состояние держится, может стрелять повторно, но **не
чаще раза в 2 минуты, от КОНЦА прошлого прогона** (последнего ответа проб, не
старта — длинный прогон по большой мёртвой группе не должен позволять
следующему шторму стартовать впритык). Параллельные прогоны схлопывает
существующий `checking`-CAS; штатный тикер продолжает свой ритм (у мёртвых
history удалена — их и так перепробуют каждый interval).

**passive_check × аварийный режим.** Пока действует аварийный режим,
passive-skip проб отключён: иначе рабочий запасной пассивно подтверждается,
циклы пропускаются, и оштрафованный бывший лучший никогда не получает пробу,
которая сбрасывает его штрафы, — группа зависла бы на запасном навсегда.

**UDP** штрафов не генерирует (у `ListenPacket` нет connect-сигнала), но
выбором пользуется общим (`pickForDial`).

### Принятые компромиссы

- **Причинная неоднозначность принята без дедупа по назначениям** (решение
  владельца): один заблокированный сайт с упорным клиентом может уронить группу
  в аварийный режим. Деградация мягкая — выбор уходит на здоровые узлы, всё
  работает, штрафы смываются первым же ответившим ретестом. Логику дедупа
  сочли не окупающейся.
- Директива дельт соблюдена: ни одного нового таймера — все проверки
  (уровень-триггер, 2-минутная пауза) считаются в момент события по
  timestamp-дельте; при doze-заморозке монотонных часов дельта ошибается в
  консервативную сторону (откладывает шторм, не учащает).

## Верификация

[urltest_penalty_lx_test.go](../../../protocol/group/urltest_penalty_lx_test.go):
классификация ошибок (таблица, включая обёрнутые); двухуровневое ранжирование
(порог, победа меньших штрафов над скоростью, возврат после сброса); fallback
(штраф, перенос выбора, ровно одна запасная попытка, отказ назначения не
триггерит); уровень-триггер клапана (частичное здоровье не стреляет, тотальное
стреляет, дельта-лимит держит, отсчёт от конца прогона); passive-skip отключён
в аварийном режиме и проба сбрасывает штрафы. Полный пакет `protocol/group` +
сборка полным набором тегов — зелёные.
