# SPEC 139 — Настраиваемый ClientHello uTLS

**Фича:** [019-CUSTOM_UTLS_HELLO](../../FEATURES/019-CUSTOM_UTLS_HELLO/FEATURE.md)

| Поле | Значение |
|------|----------|
| Тип | F |
| Статус | I |

Клиент должен принимать `tls.utls.fingerprint: "custom"` вместе с `tls.utls.client_hello`, отклонять неполный или некорректный профиль до дозвона и отправлять ClientHello с заданным порядком шифров и расширений. Для неименованных расширений поддерживается числовой ID и статический payload в base64. Готовые профили не должны измениться. Серверной части нет.

## Приёмка

- Красный/зелёный тест проверяет реальный ClientHello и успешное TLS-рукопожатие.
- Тест проверяет числовой ID и байты расширения на проводе.
- Невалидный и неполный конфиг отклоняются с понятной ошибкой.
- Сборка без дополнительного тега не включает возможность.
- Тесты затронутого пакета проходят с обоими наборами тегов.
