## Обход мёртвого слота

Выбор `round_robin` пропускает слот без history, ключи пропущенных слотов расходятся по живым
поровну. Коммиты `97f6ff4f5`, `93a1cdbce`, PR [#54](https://github.com/Leadaxe/sing-box-lx/pull/54),
в релизах с `v1.14.3-lx.23`. Тесты — `protocol/group/urltest_rr_skip_lx_test.go`: пять из восьми
падали до правки выбора.

**A/B на роутере** 2026-10-22: OpenWrt, aarch64, боевой конфиг владельца отчёта — пул 3 из 4,
`pool_tolerance: 700`, без sticky, `interval` 3,667 с, четыре узла на двух серверах. Бинари —
`v1.14.2-lx.11` и он же с патчем, оба собраны `lx-release.yml`. Простой сервера 1 — правило nft:
45 с чёрной дыры, затем 30 с отказа RST. Нагрузка — 4 новых HTTPS-соединения в секунду через tun.

- Стоковое ядро: около трети новых соединений падает весь простой.
- С обходом: ни одного отказа после первых 15–20 с простоя, в обоих режимах.
- RST окно обнаружения не сократил; причина не разбиралась.

## Проверка

- lx-ci (`protocol/group`, `common/trafficcontrol`, `common/urltest`, `daemon`, пакеты отказов
  назначения и рукопожатий SPEC 161, под `-race`, теги `with_lx_command` и соседние) — зелёный на
  каждом раунде; последний — run 45700227934 на `a8a6de5a0`.
- Стенд 8 на NanoPi (после переписывания под алгоритм): убитый узел — 0 потерь, вычёркивание 0,9 с;
  обрыв сети — 11 чистых прогонов из 12; находки — ложное вычёркивание мигающего узла, SOCKS
  `code=1` как отказ сайта, вычеркнутый узел в слоте, уход клиента как молчание сайта, пробы замены
  вне бюджета — ушли в раунд 9.
- Стенд 9: зависший узел 41,4 с, убитый 0,92 с, группа 300 с пятью живыми — замена из запаса за
  0,02 с; находки — раскладка прогона против заполнения в прогоне, ступени паузы на раунд позже,
  двойная проба кандидата — исправлены (строка «Стенд 9» выше).
- Стенд 10 — итог в [SPEC.md](SPEC.md#как-проверено). Находки: молчащий узел в стартовом пуле
  задерживает первый прогон на 15 с (ограничение), плановый прогон возвращал в слот узел,
  вычеркнутый в его интервале, раскладка отдавала пустой слот вычеркнутому узлу при живом запасе —
  исправлены финальной правкой. Разница процессора между сборками на коротких соединениях
  меняла знак вместе с бинарём серверов стенда — артефакт стенда, паритет.
- `impair` на loopback (сборка `66fd04e19`): Q2, граница D1 (проба 10 с — жив, 18 с — вычеркнут
  через время по L1), Q4 и снятие карантина прогоном, проверки без вердикта и ступени паузы при
  обрыве на всех узлах. Найдено: плановый прогон в обрыве без сигнала пересобирал пул — исправлено
  финальной правкой («прогон без ответа ничего не меняет»).
