## Обход мёртвого слота

Выбор `round_robin` пропускает слот без history, ключи пропущенных слотов расходятся по живым
поровну. Коммиты `97f6ff4f5`, `93a1cdbce`, PR [#54](https://github.com/Leadaxe/sing-box-lx/pull/54),
в релизах с `v1.14.3-lx.23`. Тесты — `protocol/group/urltest_rr_skip_lx_test.go`: пять из восьми
падали до правки выбора.

**A/B на роутере** 2026-10-22: OpenWrt, aarch64, боевой конфиг владельца отчёта — пул 3 из 4,
`pool_tolerance: 700`, без sticky, `interval` 3,667 с, четыре узла на двух серверах. Бинари —
`v1.14.2-lx.11` и он же с патчем, оба собраны `lx-release.yml`. Простой сервера 1 — правило nft:
45 с чёрной дыры, затем 30 с отказа RST. Нагрузка — 4 новых HTTPS-соединения в секунду через tun.

- Стоковое ядро: около трети новых соединений падает весь простой.
- С обходом: ни одного отказа после первых 15–20 с простоя, в обоих режимах.
- RST окно обнаружения не сократил; причина не разбиралась.
