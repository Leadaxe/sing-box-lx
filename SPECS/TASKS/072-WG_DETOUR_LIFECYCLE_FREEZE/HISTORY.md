# HISTORY — 072-WG_DETOUR_LIFECYCLE_FREEZE

## 2026-08-18 — задача рождена слиянием 070 + 071 + разбор дампа 2026-08-17

**Решение владельца:** 070 и 071 — одна семья полевых отказов жизненного
цикла WG-эндпоинта (краш на гонке start/close, фриз на мёртвом detour), и
третий полевой дамп лёг ровно между ними: его цепочка проходит через зоны
обеих задач и корень нашёлся в третьей (v2rayxhttp). По §3.2 конституции —
одна зона ответственности = одна задача-владелец; владельцем семьи стала
новая 072, каталоги 070/071 оставлены указателями, их кодовые маркеры
(`// lx: SPEC 070`, `// lx: SPEC 071`) не переименовывались, чтобы не гонять
дифф по upstream-смежным файлам.

**Хронология механизмов:**

1. `v1.14.0-lx.27-rc.2` отгрузил механизмы 1–2 (гейт start/close — бывший
   SPEC 070; ограниченный dial + отвязанный pause-диспатч — бывший SPEC 071)
   по дампам 2026-08-12 (54 мин фриза) и 2026-08-16 (SIGSEGV).

2. Дамп 2026-08-17 (rc.2, обе правки в бинаре, 38 мин фриза) показал, что
   закрыто окно, а не класс:
   - сторож SPEC 050 снимается по `created`, а `created` закрывается и при
     ПРОВАЛЕ roundTrip — error-ветки не разбивали upload-пайп, и Write
     хендшейка VLESS завис навечно уже без сторожа и без дедлайна
     (`connAccess` + `device.net.RLock` → BindClose → pauseOpAccess →
     Endpoint.Close → Manager.Close → все DetourDialer.init);
   - HTTP-запросы XHTTP ездили на dial-контексте, и 15-секундный дедлайн
     механизма 2, отработав, **рвал живой стрим** (http2 привязывает жизнь
     стрима к ctx запроса): каждый здоровый detour-conn WG пересоздавался
     каждые 15 с, заново бросая кости на дыру выше. Диагноз-гипотеза
     владельца о цепочке подтвердилась дословно, с двумя поправками:
     read-lock `device.net` держал сам g275 (`Peer.SendBuffers`), а не
     receive-горутина; и «добавить таймаут на dial» уже было сделано в rc.2 —
     не сработало из-за двух дыр выше.

3. Механизмы 3–4 (разбитие пайпа на провале raise; conn-scoped контексты
   запросов + per-post бюджет packet-up) добавлены этим слиянием;
   red/green — `transport/v2rayxhttp/raise_failure_test.go`.

**Судьба прежних текстов:** содержимое SPEC.md задач 070/071 (постановка,
разбор дампов 08-12/08-16, обоснования «что намеренно не сделано») поглощено
SPEC.md этой задачи в сжатом виде; полные тексты доступны в git-истории
каталогов 070/071 до коммита слияния.
